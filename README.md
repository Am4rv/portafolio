# Portafolio Windows XP Luna — Amaru Ríos Figueroa

Portafolio interactivo personal de **Amaru Ríos Figueroa** (Software Engineer & Desarrollador Full-Stack), diseñado con la estética nostálgica y detallada de **Windows XP Luna**.

---

## 🌟 Características Principales

### 1. Sistema Operativo Virtual (AmaruOS XP)
- **Fondo de Pantalla Bliss**: Arte vectorial y CSS escalable con colinas verdes y nubes flotantes animadas.
- **Barra de Tareas & Botón Inicio**: Menú inicio clásico de 2 columnas con avatar de usuario, acceso a programas, accesos directos y diálogo de apagado.
- **Gestor de Ventanas Completo**:
  - Arrastre con puntero (mouse y pantallas táctiles).
  - Redimensionamiento desde esquinas.
  - Minimizar a la barra de tareas, Maximizar / Restaurar y Cerrar con controles retro.
  - Gestión de foco y capas z-index.
- **Selección de Iconos**: Cuadro de selección elástico en el escritorio y doble clic para abrir aplicaciones.
- **Efectos de Sonido Retro (Web Audio API)**: Chime de inicio de Windows XP, clics, alertas ding, vaciado de papelera y sonido de apagado sintetizados por código sin archivos externos pesados.

## 🚀 Cómo Ejecutar Localmente

### Opción 1: Con Python (Inmediato sin instalar dependencias)
```bash
python3 -m http.server 3000
```
Luego abre tu navegador en `http://localhost:3000`.

### Opción 2: Con Node.js / npm
```bash
npm start
```
